## 📈 Philosophie d'apprentissage

Je considère que les compétences en cybersécurité s'acquièrent grâce à une **pratique concrète et continue**. Pour chaque exercice pratique (lab), je m'efforce de documenter les éléments suivants :

1. L'objectif
2. L'environnement
3. Les outils utilisés
4. Les commandes exécutées
5. Les observations
6. L'analyse
7. Les implications en matière de sécurité
8. Les enseignements tirés

L'objectif n'est pas seulement de réaliser des exercices de formation, mais de comprendre **comment ces concepts s'appliquent aux opérations de sécurité en conditions réelles**.
